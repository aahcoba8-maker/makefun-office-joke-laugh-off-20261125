Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun: one original one-line joke about office life, judged pairwise by an AI comedy-club judge.

## The joke

> I asked my boss for a raise and he gave me a standing desk — technically, I'm taller now.

## How it works

`main.py` (Python 3, standard library only) writes the joke to `entry.txt` in the output directory the grader provides (`MAKEFUN_OUTPUT_DIR`, falling back to the script directory). The file holds exactly the joke bytes — 89 characters, no trailing newline — inside the 1–200 character gate, and the program checks the gate itself before writing.
